Назначение
Обеспечить ввод данных пациента травматологии через GUI.

Поля и блоки
Общее

Номер истории — число.
1.1. Анамнез

Диагноз — выбор из списка (выпадающий список).
Для перелома плечевой кости: тип перелома (закрытый / открытый / со смещением / без смещения), место (дистальный / проксимальный отдел).
Для перелома лодыжки: тип (закрытый / открытый), место (внутренняя / наружная лодыжка).
Состояние после — выбор: интрамедуллярный остеосинтез, накостный, Г-образная пластина, пластика ПКС, эндопротезирование сустава.
Период после операции — ранний послеоперационный, ранний восстановительный, поздний восстановительный, поздний послеоперационный.
1.2. Объективное состояние

Возраст — число, лет.
Сила мышц (здоровых конечностей) — есть ли нарушения; локализация (справа/слева, верх/низ и т.д.).
Сгибание в тазобедренном суставе — балл, диапазон (от–до).
Разгибание в коленном суставе — балл, диапазон.
Принятие положения стоя — от «незначительное затруднение» до «невозможно без помощи».
1.3. Опрос — вопросник DASH

Пункты 1–4 (банка с крышкой, писать, повернуть ключ, готовить пищу) с вариантами: не трудно (1 балл), трудно (3 балла), невозможно (5 баллов), с полями для текста.
Примечания из ТЗ
В перспективе более 50 показателей; желательно хранить описатели в отдельном файле и подгружать в GUI для гибкости.
Сохранение данных
Нужно сохранять введённые данные; на этапе прототипа предложен упрощённый вид: номер истории, диагноз (название, уточнение, значение), возраст (факт, уточнение, значение).
Формат выходного файла с описанием пациента в итоге будет фиксированным.
