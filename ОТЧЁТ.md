# Отчёт

Старая форма была короткой: диагноз, перелом, опрос DASH и несколько полей. Список ответов был написан вручную в файле `описатели.js`.

Преподавательница прислала файл с готовыми названиями и вариантами ответов. Форму я не заменял на новую программу, а переделал эту же. Теперь вопросы и ответы берутся из её файла.

Что получилось:

- Три раздела, как в её файле: общие сведения, сведения о состоянии, сведения в динамике.
- У каждого поля то название, которое записано у неё. Например, возраст, пол, клинический диагноз.
- Если в файле список, на экране выпадающий список. Если число, поле для числа и единица измерения, например «лет».
- Если признак может быть «есть» или «нет», дополнительные поля открываются только когда выбрано «присутствует».
- Кнопка «Сохранить данные (JSON)» скачивает только то, что заполнено.

Её файл лежит в проекте как `признаки.json`. Старые файлы формы тоже оставлены.
