# Прототип GUI травматологии — инструкция

Все интерфейсные тексты на русском. Папка проекта: `travma-gui`.

---

## Как запустить

1. Откройте папку `travma-gui` на компьютере.
2. Дважды щёлкните по файлу **`index.html`** — он откроется в браузере по умолчанию (Chrome, Edge, Firefox и т.д.).
3. Дополнительные программы (Node, Python, сервер) **не обязательны**.

Если преподаватель или браузер требуют открывать страницу только с «локального сервера», можно в папке `travma-gui` выполнить в терминале:

```bash
python -m http.server 8080
```

После этого в браузере откройте адрес: `http://localhost:8080`

## Как протестировать

1. **Общие сведения:** введите номер истории (число).
2. **Анамнез:** выберите «Перелом плечевой кости» — появятся тип перелома и **место** (можно отметить **несколько** чекбоксов: дистальный и/или проксимальный отдел). Для «Перелом лодыжки» — тип и одно место из списка. Смена диагноза скрывает ненужный блок.
3. Заполните «Состояние после» и «Период после операции».
4. **Объективное состояние:** возраст; блок **«Сила мышц»** — сначала наличие нарушений; при «нарушена» появится **«Место»**; баллы суставов и положение стоя.
5. **DASH:** для каждого из четырёх пунктов выберите балл 1–5. В JSON будет также **сумма баллов**.
6. Нажмите **«Сохранить данные (JSON)»** — в папку **«Загрузки»** браузера сохранится файл вида `пациент_2025-03-24-12-30-00.json`.
7. Откройте этот файл в блокноте или VS Code и убедитесь, что структура данных читается и совпадает с заполненной формой.
8. Кнопка **«Очистить форму»** сбрасывает все поля (с подтверждением).

## Как улучшить (для следующих версий)

- **Валидация:** обязательные поля (например, номер истории и диагноз) с подсветкой ошибок перед сохранением.
- **Больше показателей:** вынести новые поля в `описатели.js` и при необходимости генерировать часть формы скриптом.
- **Фиксированный формат выхода:** согласовать с преподавателем точную схему JSON и при необходимости добавить кнопку экспорта в другой формат.
- **Доступность:** улучшить связи «метка — поле» для скринридеров, контраст при проверке по WCAG.
- **Сервер:** при учёбе на бэкенде — сохранять данные в базу вместо скачивания файла.
- **Офлайн-шрифты:** подключить шрифты локально, если сдача без интернета обязательна.

## Состав файлов

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка формы |
| `styles.css` | Оформление (тёмная тема, акценты) |
| `описатели.js` | Списки значений (`TRAVMA_DESCRIPTORS`) и режим «один/несколько» (`TRAVMA_VALUE_CHOICE`) |
| `app.js` | Логика: показ блоков, сбор данных, сохранение JSON |

Удачи с защитой работы.
